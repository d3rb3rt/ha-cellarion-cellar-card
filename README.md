# My Cellarion (work in progress)

Home Assistant dashboard card and data integration for [Cellarion](https://cellarion.app):
searchable, filterable cellar inventory, bottle details and taking a bottle out.

Status: early scaffold. The data layer (`custom_components/my_cellarion/api.py`) is ported from a working
private setup; the Home Assistant glue (config flow, services, card registration) follows.
