## What's new in 1.0.0

### Added
- **Appellation filter** (e.g. Côte des Bar, Saar); it appears in the filter settings and can be reordered or hidden.
- **Other category** (beer, cider, …) in the type filter, with a three-dot icon. A setting hides Other items from the list unless the type filter "Other" is chosen; a search term still finds them. The setting can be shared by all devices or set per device.
- **Force full width** (Appearance, this device only): on wide screens the list, header and alphabet bar use the whole width.
- **Info behind the wine name** in the list can be shared by all devices or set per device.
- **Search** also finds wines by the values of your personal data fields (e.g. sweetness "feinherb") and highlights hits in grapes and personal data shown in the list.
- **Edit in Cellarion** button with the Cellarion logo in the detail dialog.
- New README with features, settings, services and troubleshooting, plus new screenshots.

### Changed
- In the settings, **Filters** and **List** are two separate sections.
- In English, the "Location" filter and detail field are called "Storage".
- The card no longer focuses the search field on start.

### Fixed
- The detail view shows the label photo even if it is attached to another bottle of the same vintage.
- Reordering rows in the settings by mouse no longer stops after one position.
- Filters whose name contains parentheses no longer reappear after a reload when hidden in the settings.
- Personal-field filters that only apply to Other items no longer disappear while Other items are hidden.
- The search field no longer shows two clear buttons.
- Filters no longer hide while scrolling when the list has 10 entries or fewer.
