## What's new in 2.1.0

### Rack picture in the bottle details
- New **rack button** in the bottom bar of the detail view (between *Take out* and the Cellarion link). It opens a large picture of the rack: label image and data on the left, the rack with all shelves and rows on the right.
- Places of the open vintage are highlighted, the selected bottle is solid. **Tap a bottle** to start the take-out for exactly that bottle.
- If the wine is stored in several racks, switch between them with the **arrows or by swiping** over the rack; dots show which rack you are on.
- Tap the rack button again to return to the details.

### Take-out dialog
- The dialog now names the **exact position** of the bottle: rack, shelf, row and slot, regardless of the place display setting.

### Phone
- The Cellarion link in the detail bar shows only the bottle logo to save space.

### Under the hood
- The data layer delivers the rack layout (rows per shelf, places per row) that the rack picture needs.
