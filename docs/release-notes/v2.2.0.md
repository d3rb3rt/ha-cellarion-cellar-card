## What's new in 2.2.0

### Changed
- **Classification follows Cellarion's new tier system:** the single *Classification* filter is replaced by one filter per kind of tier, as Cellarion now groups them: *Vineyard rank* (e.g. Grosses Gewächs, VDP Grosse Lage, Grand Cru), *Ripeness* (e.g. Kabinett, Spätlese, Smaragd), *Ageing* and *Other*. Tiers are listed in a fixed order, and empty kinds are hidden.
- **Filters now hold one value.** Picking a value replaces the previous one; the list keeps offering the other values, and a **"Selected: …"** line at the top shows the current choice.

### Added
- **Combine grapes with AND:** the **&** button next to a grape (with the number of matching wines in brackets) requires wines to contain all chosen grapes. Chosen grapes are shown as one bordered group with & between them.
